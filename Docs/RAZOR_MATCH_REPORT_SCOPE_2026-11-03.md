# Match reports — scope before code

Gain: optional readable report for current/finished match and actual archived
career fixtures; compare team counters, identify recorded athlete contributions
and see fact-based next-practice suggestions. Existing full-time flow unchanged;
do not automatically open a modal or fabricate an event timeline, shot quality,
possession percentage, MVP award or causal explanation. No engine/rules/AI/RNG,
save schema/journal, native/PEX/CK/reward/sibling change.

Authority: current validated engine snapshot or accepted season fixture. A report
is derived on opening, never persisted or published. Team shots/pass attempts/
challenges/saves/clock turnovers come from actual counters. Completed passes and
player rows only from12 tracked individual rows; coverage starts at actual
metricsFromTick, labeled when partial. Do not combine partial completed passes
with full-match attempts as a fake completion rate. Legacy four-team archived
fixtures have only goals: show known score and unavailable-detail explanation,
never synthetic zeros. Historical names use that archived season's frozen roster
and fixture lineup. Non-league players get side/jersey labels, not invented names.
All eligible athletes shown; tied contributors do not receive invented MVP honours.

Lifecycle: setup/pause/result -> Match report -> explicit close -> remain paused
or select next match. Clicking from live gameplay pauses through existing panel
path. No clock advance, reward/finish/save publication caused by rendering itself
(normal pause checkpoint unchanged). Report can display pending completed league
match during settlement; data taken from that actual match, not next opponent.
After league reload, latest player fixture remains available even with match:null.
History -> report round -> optional Back to previous season link preserves history
index; normal Back/ESC closes to paused match/dashboard. No new timers/cadence. Modal LB/RB (Shift/C/Control) and PageUp/PageDown page the panel without triggering match sprint/receiver actions; applies consistently to all Razor panels. Hint visible beside Back.

None/empty/no previous match hides entry or reports unavailable. Zero attempts
do not divide by zero. Missing/invalid counters never treated as recorded zero;
partial/legacy coverage explained. Reload reconstructs from existing saves;
corrupt/future saves continue existing preservation guards. Return/blur/hidden/
unload/travel/death/quest stop follow existing checkpoint/panel teardown; no new
world mutation or new persistent lifetime. Reports disappear on uninstall while
all gameplay saves remain valid.

Horizontal seams: engine turnover semantics and stat names; current state vs
latest accepted fixture vs frozen archived roster; practice/drill/legacy/career;
panel pause/inert/focus/forwarded controller; no native practice publication;
existing prize claim/settlement; script order + packaging. Fictional game facts
remain in Starcade: CT real personnel, SSSE economy, Legacy real history, AISS
narration unchanged; no external adapter, extra game/catalog entry or polling.
