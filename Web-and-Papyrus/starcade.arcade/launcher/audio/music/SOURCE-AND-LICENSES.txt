STARCADE BACKGROUND MUSIC - SOURCE AND LICENSE NOTICE

WHAT THIS IS
  28 royalty-free 8-bit/chiptune-style tracks, supplied directly by X-2357
  (Michael) from his own downloaded collection, played as looping background
  music across the Starcade library screen. Starcade plays them in a
  per-session shuffled order via a plain HTML5 <audio> element in the
  launcher shell (main.js) - no third-party player library or network
  fetch is involved; every file is bundled locally under this folder.

STARCADE-SIDE INTEGRATION
  Added by Claude (Sonnet 5) at Michael's request, 2026-08-30. Music plays
  only in the library/menu screen, in a shuffled order, and auto-advances
  when a track ends. It pauses automatically when an embedded game opens
  (so it never plays under a game's own audio) and resumes when returning
  to the library. Off by default; the on/off state persists locally
  (localStorage) across sessions, matching how Starcade already persists
  high scores and saves. External launches (OpenMW) do not pause it, since
  those open in a separate OS window with no audio conflict.
