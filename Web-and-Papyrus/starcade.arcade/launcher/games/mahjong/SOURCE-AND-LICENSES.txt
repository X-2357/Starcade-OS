SCORING AND SAVES
  Mah Jong is not yet wired into Starcade's arcade leaderboard/XP system -
  StarcadeHost.finish() is never called. It manages its own save/progress
  state entirely internally via this page's own browser storage, independent
  of Starcade's own per-game save slot, the same way Micropolis does.
